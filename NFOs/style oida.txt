🧬 Die wichtigsten Songstrukturen

Diese Struktur-Tags kannst du unabhängig vom Genre kombinieren:

1. Klassischer Rap-Banger

[Intro] → [Verse 1] → [Hook] → [Verse 2] → [Hook] → [Outro]

Eigenschaften: sofort verständlich, Hook bleibt hängen, klassischer Single-Aufbau.

2. 90s Boom-Bap

[DJ Intro] → [Verse 1] → [Hook] → [Verse 2] → [Scratch Break] → [Verse 3] → [Hook] → [Outro]

Tags:
[Dusty Samples] [Vinyl Crackle] [Hard Drums] [DJ Scratches] [Punchline Rap]

3. Beat-Switch-Monster

[Intro] → [Verse 1] → [Hook] → [Beat Switch] → [Verse 2] → [Beat Switch] → [Final Hook]

Tags:
[Beat Switch] [Tempo Change] [Key Change] [Flow Switch] [Double Time] [Half Time]

Das ist besonders stark, wenn der Track mehrfach seinen Charakter verändert, statt vier Minuten denselben Loop zu fahren.

4. Cinematic Story

[Cinematic Intro] → [Verse 1] → [Hook] → [Verse 2] → [Bridge] → [Climax] → [Final Hook] → [Outro]

Tags:
[Cinematic] [Storytelling] [Sound Design] [Character Voices] [Dramatic Build]

5. Freestyle / Cypher

[DJ Intro] → [MC 1] → [MC 2] → [MC 3] → [Scratch Break] → [MC 4] → [Final Cypher]

Tags:
[Cypher] [Freestyle] [Multiple MCs] [Call And Response] [DJ Scratches]

6. Trap/Drill

[Intro] → [Hook] → [Verse] → [Hook] → [Verse] → [Beat Drop] → [Final Hook]

Tags:
[808 Sub Bass] [Hi-Hat Rolls] [Sliding 808] [Beat Drop] [Adlibs]

7. Party Rap

[Hype Intro] → [Hook] → [Verse] → [Hook] → [Dance Break] → [Verse] → [Final Hook]

Tags:
[Party Energy] [Crowd Chant] [Call And Response] [Dance Break] [Hype Adlibs]

8. Progressive Hip-Hop

[Intro] → [Verse] → [Hook] → [Instrumental] → [Beat Switch] → [Verse] → [Bridge] → [Final Switch] → [Outro]

Tags:
[Progressive Hip-Hop] [Multiple Beat Switches] [Dynamic Arrangement] [Genre Fusion]

🧪 SUNO 4.5 — wichtige Struktur-Tags

Für komplexere Tracks würde ich die Tags hierarchisch denken:

[Genre]
[Mood]
[Tempo]
[Drums]
[Bass]
[Instruments]
[Vocal Style]
[Flow]
[Structure]
[Production]
[Transitions]

Wichtig: Suno-Tags sind keine harte Programmiersprache. Sie funktionieren eher als Arrangement-/Stil-Hinweise; je konkreter und widerspruchsfreier die Kombination, desto besser. Für einen starken Track würde ich deshalb nicht 40 Genres gleichzeitig draufklatschen — lieber 1 Hauptgenre + 2–4 Substyles + konkrete Arrangement-Tags.
