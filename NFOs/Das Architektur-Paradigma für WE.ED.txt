Das Architektur-Paradigma für WE.ED.IT OIDA (v8 Vision) definiert das System nicht als Schnittsoftware, sondern als Music Video Compiler & Dynamic AST Engine.

Die Entkopplung von deklarativer Absicht (FilmAST) und deterministischem Render-Pass verwandelt die Videogenerierung in ein semantisches Compilations-Problem.

interface FilmAST {
  id: string;

    title: string;

    timestampEnd: number;

    primaryEmotion: string; // e.g., "tension", "victory"
    targetEnergy: number;
  }>;
  scenes: SceneNode[];

interface SceneNode {
  sceneId: string;
  semanticTags: string[]; // ["city", "night", "smoke"]
  locationContext: string;
  dominantColorPalette: string[]; // Hex color codes
  shots: ShotNode[];
}

interface ShotNode {
  shotId: string;
  durationSec: number;
  energyLevel: number;

    movement: "push" | "pull" | "pan" | "orbit" | "static";
    velocity: number;
    lensType: "wide" | "macro" | "telephoto" | "handheld";
  };
  transitionOut: {
    type: "cut" | "whip" | "dissolve" | "match_cut";
    speedMs: number;
  };
  frames: FrameConstraint[];
}

interface FrameConstraint {
  frameIndex: number;
  cropRatio: number;
  zoomFactor: number;
  lutProfile: string;
  colorGradingMemory: {
    hueShift: number;
    saturation: number;
    brightness: number;
  };
}

5. Implementation Stack & Core Pipeline
Rust
// Core Representation of Visual Transformer Pass
pub struct TimelineCompiler {
    pub ast: FilmAST,
    pub clip_pool: Vec<ClipAST>,
}

impl TimelineCompiler {
    pub fn compile_global_graph(&mut self) -> RenderGraph {
        // 1. Resolve Semantic Matches
        let matched_timeline = self.resolve_genome_matching();
        
        // 2. Apply Visual Transformer (Color Balance, Pacing Adjustments)
        let transformed_timeline = self.apply_visual_transformer(matched_timeline);
        
        // 3. Optimize Graph via State Engine (Continuity & Memory)
        let optimized_graph = self.optimize_continuity(transformed_timeline);
        
        // 4. Generate Final Deterministic Render Pipeline Script
        self.generate_render_instructions(optimized_graph)
    }

    fn apply_visual_transformer(&self, mut nodes: Vec<ResolvedShot>) -> Vec<ResolvedShot> {
        // Example Rule: "Too much orange -> Inject blue/neutral contrast"
        for window in nodes.windows_mut(3) {
            if is_monotonous_color(&window, "orange") {
                inject_color_contrast(&mut window[2], "cyan_blue");
            }
        }
        nodes
    }
}
6. Summary Evaluation Strategy
Phase	Transformation Input	Compiler Action	Resulting Node
Parsing	Raw Song / Lyrics / Sidecar	Unrolls Audio Features into Structural Hierarchy	SongAST (Theme → Emotion)
Semantic Matching	SongAST + ClipAST Pool	Calculates Vector Proximity & Semantic Distance	Unoptimized Timeline Graph
Optimization	Unoptimized Graph	Global State Check (Camera, Color, Rhythm Memory)	Optimized Render Graph
Execution	Optimized Render Graph	Deterministic FFmpeg / GPU Pipeline Render	Finished Film Output
Dieses System macht WE.ED.IT OIDA v8 zu einem deterministischen Film-Compiler, der abstrakte musikalische und visuelle Intentionen verarbeitet und über ein erweiterbares Film Genome kontinuierlich lernt, wie Filme strukturiert werden.
